# BHUMISETU Geospatial & Public Datasets Reference

This directory stores sample pre-clipped datasets (< 50 MB total) for the demo district **Sehore & Budhni Highway Corridor, Madhya Pradesh, India**.

The application operates in **offline-safe mode**, utilizing pre-clipped sample files bundled in `data/sample/`. Optional live downloads of public datasets can be executed via `python scripts/download_datasets.py`.

## Data Privacy & Ethics Statement

> [!IMPORTANT]
> **Synthetic Land Parcel Notice**: Real land records and landowner identity details in India are strictly private. All parcel polygons, khasra numbers, owner names (e.g., *Ramesh Chandra Sharma*), and dispute details in BHUMISETU are synthetic data generated by `scripts/generate_synthetic_parcels.py`. These synthetic records are explicitly tagged with `is_synthetic = true` and rendered with a visible **"Demo Data"** badge throughout the user interface.
